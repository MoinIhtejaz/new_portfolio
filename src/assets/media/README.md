# Project media

Drop a screenshot or screen recording here, named after the project's
`mediaKey` (see `src/data/portfolio.ts`), and it will automatically appear
on the project showcase. Delete the file to hide it again.

| mediaKey     | Project                          | Example file       |
| ------------ | -------------------------------- | ------------------ |
| `volatility` | Future Volatility Forecasting    | `volatility.mp4`   |
| `optimiser`  | Stock Portfolio Optimisation     | `optimiser.png`    |
| `pipeline`   | End-to-End Automated Data Pipeline | `pipeline.webm`  |
| `bloom`      | Efficient Email Filtering System | `bloom.jpg`        |

Supported formats:

- **Images:** png, jpg, jpeg, webp, gif, svg, avif
- **Videos:** mp4, webm, mov, m4v (autoplay muted on loop)

One file per project (if several match, the first found wins).
